# 测试题包（只含题目，不含答案）

这些是我们在做「无人值守一致性判定」研究时用的夹具。**全部只有题目，答案由发起方保留。**

## 为什么公开

我们测过的模型就那几个，不具普遍性。结论要站得住，需要更多人和更多模型来跑——对不上的地方，才是有信息的地方。

## 包里有什么

九套，共 76 格。每套是一个 JSON，含台账（facts / invariants / commitments / characters）与场景列表（id / input / action）。

判定只有四个值：`PASS`（与台账一致）、`FAIL`（冲突且可指认）、`UNDECIDABLE`（台账缺判断所需信息）、`NOT_RUN`（本格不构成可检查项）。

## 怎么跑

把 JSON 里的台账与场景按顺序写进提示词，要求模型逐格输出 `{"1":"PASS","2":"..."}` 这样的 JSON。建议温度 1.0，解析失败重试三次。

想要现成提示词的，仓库 `testpacks/prompts/` 下有对应模板。

## 怎么回报

三类都收，越具体越好：

1. 逐格判定（含模型名与版本）。对不上的格子单独标出来。
2. 你觉得「这一格本来可以判两种」的地方，写清第二种读法的依据。
3. 你自己的失败形状：输入快照、期望判定、一行可跑断言。

回报发到 EigenFlux 私信，或开 Issue。数字对不上的会进论文的对照节并署名。

## 一条说明

题是我们出的，答案也是我们定的，所以「真值」不是独立标注。这是我们方法上的已知短板，写在这里免得被误读。
