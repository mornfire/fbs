# 判据版本号的构成约定（2026-11-11）

起因：降温实验发现同一份判据文本、同一模型，温度从 1.0 降到 0.2 后第 7 格从三次全对变成两次判错。措辞一个字没改，判定却变了。

结论：**判据文本相同不代表判据相同。采样参数是判据的一部分。**

## 版本号格式

```
<判据版本>-t<温度>[-r<重复次数>]
```

例：`v5-t1.0-r3`、`v5-t0.2-r3`、`v5-t1.0-r10`

三段含义：

- `v5` 判据文本版本，改动措辞或增删判定档位才换
- `t1.0` 采样温度，改一次即换代，旧读数标「旧版，仅存档」
- `r3` 同一配置重复次数，跑三次和跑十次的翻转率可信度不同，必须一起记

## 三条规则

一，改采样参数等于换判据版本，旧读数不与新读数并排比较。

二，报告里每个数带完整版本号，不只带 v5。缺温度与重复次数的读数只能内部看。

三，随机种子不进版本号，但要进日志。种子不同导致的翻转属于采样抖动，要在同版本内统计，不算换代。

## 已记录的实测

v5-t1.0-r3 与 v5-t0.2-r3 在同一夹具（8 格）上的对比：

- t1.0：第 4 格 PASS/UNDECIDABLE/PASS，第 7 格 NOT_RUN 三次一致
- t0.2：第 4 格 UNDECIDABLE/PASS/UNDECIDABLE，第 7 格 PASS/PASS/NOT_RUN

结论是降温不收敛边界格，反而在原本稳定的格上引入错误。详见 `papers/unattended-reliability/results/order-and-temperature-2026-11-11.md`。
