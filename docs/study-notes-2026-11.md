## 一、NarraWorld：长篇写作的结构化记忆（arXiv:2609.32401）

**它做了什么**：把长篇写作的记忆构建当成「世界创建」。从一张有证据锚定的共享图出发，派生四个互相连通的视图：

1. **世界事实**（world facts）— 客观设定
2. **每角色信念**（per-character beliefs）— 某个角色以为的事实
3. **未闭合发展线**（open developments）— 伏笔与待解线
4. **假设分支**（hypothetical branches）— 可能世界

层级聚合（原子闭合）把事件合并成场景、情节线、情节，每一层都能追溯到原始文本片段。检索用「计划式重建」：先从当前叙事处境与记忆预览推断查询依赖，再在 token 预算内组装相关记录。

**对我们的意义**

- **印证**：我们那套「条目 ID + 版本 + 下游 stale 重算」方向是对的——它同样强调可追溯到源片段。
- **我们缺两块**：**每角色信念**（角色不知道的事不能被他引用）和**假设分支**（可能世界）。我们之前给小剧做的 4 场景 fixture 里「角色知识隔离」正是这个视图的最小版，但服务里没落。
- **可落地**：在体检报告里新增一类冲突——「角色越权知情」（角色引用了它不在场时发生的事实）。这条规则式能查，不需要模型。

## 二、RVCBench：声音克隆的鲁棒性基准（arXiv:2602.00443）

**它做了什么**：把语音克隆的鲁棒性拆成四个管道维度，覆盖 18 个评测任务、204 个说话人、14370 条样本，评了 18 个开源模型（含 CosyVoice2、Qwen3-TTS、IndexTTS、GLM-TTS 等）。

四个维度：

| 维度 | 具体压力 |
|---|---|
| 输入鲁棒 | 参考音的口音/性别/年龄偏移；文本提示的格式异常（错字、混语）与内容域偏移（诈骗话术） |
| 生成鲁棒 | 长文本、长参考音；表达性（情绪/强调/风格）；多语言与跨语言 |
| 输出鲁棒 | 压缩与重编码：MP3 32/64k、AAC 32/64k、Opus 16/24k、电话窄带 |
| 扰动鲁棒 | 被动噪声与多人干扰（−5/0/+5/+10 dB）；主动反克隆扰动及其去噪反制 |

**关键发现**

1. **格式异常的提示会显著抬高 WER** —— 错字、混语会破坏文音对齐，导致幻觉。
2. **长文本会压垮内容准确性**，并伴随说话人身份漂移。
3. **压缩会同时损伤频谱与内容一致性** —— 生成时好听，上传后劣化。
4. **语言切换导致鲁棒性急剧下降**。
5. 指标组合：SIM（说话人相似度）、MOS（自然度）、MCD（频谱失真）、WER（内容准确）、RTF（实时率）。

**对我们的意义**

- 我们做 TTS 配音时只验了「相似度 + 回识率」两项，**缺了压缩后复检**。平台上传必然重编码，等于我们交付的质量和买家听到的质量不是同一个东西。
- **行动项**：交付前跑一次压缩复检——把成品过一遍目标平台的实际码率，再算 SIM 与 WER。这应该是语音服务的必检项，不是可选项。
- 另一个行动项：长文本配音要分段做**内容准确性抽检**，不能只抽相似度。

## 三、Agent 可靠性与静默失败（行业博客多篇）

**共同结论**（与我们已经做的重合度高）：

- 任务成功率达标 ≠ 可上线，差别在「失败是否可被观测」。
- 回归测试真正抓到静默失败，靠的是**负控样本**而不是覆盖率。
- 临床/高风险 agent 的 fail-safe 设计要求「不确证即停」，与我们的 UNDECIDABLE 语义一致。

**增量**：这几篇都强调「**可观测性要下沉到执行层**」，而不是只看业务指标。我们的对应物是「检查方式」那一行，方向一致。

## 四、由这轮学习产生的三个具体行动

1. **体检服务加一类冲突**：角色越权知情（规则式可查）。
2. **语音服务加压缩复检**：成品过目标码率后再验 SIM/WER，不通过不出货。
3. **借鉴计划式检索**：把「按当前章节相关度取前 N 条」升级为「先推断本段依赖哪些设定，再定向取」——这是我们有能力做但还没做的。
