# fbs

内容交付的可验证性工具集。用来回答一个具体问题：**这份交付到底做完了没有，怎么证明。**

不是又一个写作提示词合集。这里只有三类东西：判据、负控样本、执行器代码。

## 目录

- `docs/delivery-acceptance-checklist.md` — 交付验收清单，八条判据，每条附对应事故
- `docs/negative-control-runs.jsonl` — 六条真实负控运行记录，含两条未拦住的事故
- `docs/handoff-sample.json` — 六字段交接契约样例（改了什么 / 依赖什么 / 失效什么 / 验收条件 / 产物 / 裁定）
- `docs/ncp-fixture-4scene.json` — 四场景叙事一致性夹具（知识隔离、合法性绕行、不可判定、物理不可达）
- `docs/study-notes-2026-11.md` — 外部论文阅读笔记，非本仓库实测
- `code/` — 执行器

## 三条设计原则

**判定用四态，不用二值。** PASS / FAIL / UNDECIDABLE / NOT_RUN 分列。把「没测」记成「通过」是最常见、也最难发现的静默失败。

**未测不得进分母。** 覆盖率的分母是应跑单元全集；失败率的分母只放实际产生读数的单元。同一个未执行在两张表里一进一出，用 `(unit_id, table)` 复合键隔离。

**负控必红。** 一个从没红过的检查等于没测。所以每个判据都配必败样本，且负控要分层统计——按臂算总分会被规则层的高覆盖率拉高。

## 快速开始

需要 Python 3.10+。部分模块需要外部模型 API，通过环境变量提供：

```
DSH_CREDENTIALS   # 凭据文件路径，默认 ~/.dsh/.credentials.yaml
```

不需要模型的：

```
python code/broadcast_lint.py draft.txt
```

检查一篇广播草稿有没有修辞模板、有没有可验证的锚点。命中即返回非零。

需要模型的（语音压缩复检、设定一致性检查）需要按其文件头部的说明配置模型端点。

## 已知边界

这些没做，或者做得不够：

- **不做 i2v 视频生成**，没有任何画面侧的一致性算子。
- **说话人相似度未实现**：本机没有说话人嵌入模型，`voice_check.py` 只覆盖内容可懂度与频谱漂移，SIM 一栏标为未测量。
- **语音压缩复检的频谱阈值没有硬编码**：可接受损耗取决于目标平台，需要先用已知好/坏样本校准，硬拍阈值等于造假精确。
- **没有跨机复现的实测**：同输入同机重跑哈希一致是证明了的；换机器后是否一致依赖环境集冻结，那条只有方法，没有大规模的实测数据。
- **检索召回的漏检无法量化**：目前只有误捞的观察，没有可靠的「该捞的没捞到」指标。

## 关于数字

文档与记录里的数字都来自实际运行。凡是引自外部论文的结论，在 `study-notes` 里明确标注为阅读摘要，不是本仓库的实测结果。
